Shortest Path Finding System

Project Description

The Shortest Path Finding System is a Python-based GUI application developed for the Design and Analysis of Algorithms (DAA) subject. It helps users create a weighted graph, visualize it, and find the shortest path between vertices.

Features

Add vertices and edges.

Enter edge weights.

Visualize the graph.

Find shortest paths using Dijkstra's Algorithm.

Calculate all-pairs shortest distances using Floyd–Warshall Algorithm.

Display algorithm results.

Clear inputs or reset the graph.

Technologies Used

Math

Graph Data Structure

Algorithms Used

1. Dijkstra's Algorithm

Dijkstra's Algorithm finds the shortest path from a single source vertex to other reachable vertices in a weighted graph.

Time Complexity: O((V + E) log V) with an adjacency list and heap-based priority queue.

2. Floyd–Warshall Algorithm

The Floyd–Warshall Algorithm finds the shortest distances between every pair of vertices.

Time Complexity: O(V³)

Space Complexity: O(V²)

How to Run

Open the project notebook in Jupyter Notebook or JupyterLab.

Run the cells in order.

The application window will open.

Add vertices and edges.

Select an algorithm to calculate the shortest path.
